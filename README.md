✅ Task Manager — Lista de Tarefas

Uma aplicação web desenvolvida para facilitar a organização pessoal, o gerenciamento de atividades e o acompanhamento da produtividade.

🌐 Acesse o projeto

🔗 Task Manager — https://lista-de-tarefas-sczl.onrender.com

📌 Sobre o projeto

O Task Manager é uma aplicação de gerenciamento de tarefas que permite organizar atividades, acompanhar objetivos e visualizar o progresso das tarefas concluídas.

A proposta é oferecer uma experiência simples e intuitiva para ajudar na organização da rotina, desde pequenas atividades diárias até objetivos de longo prazo.

✨ Funcionalidades

➕ Cadastro de novas tarefas.

☑️ Marcar e desmarcar tarefas como concluídas.

🗑️ Excluir tarefas individualmente.

🔎 Filtrar tarefas entre todas, pendentes e concluídas.

📊 Barra de progresso com porcentagem de conclusão.

📈 Indicadores de tarefas totais, pendentes e concluídas.

💾 Salvamento automático das tarefas utilizando LocalStorage.

📱 Interface responsiva para diferentes dispositivos.

🛠️ Tecnologias utilizadas

React

Vite

JavaScript

Tailwind CSS

HTML5

CSS3

LocalStorage

💾 Armazenamento

As tarefas são armazenadas localmente no navegador através do LocalStorage, permitindo que continuem disponíveis mesmo após atualizar ou fechar a página.

Observação: os dados não são sincronizados entre diferentes navegadores ou dispositivos.

🎯 Objetivo

O projeto foi desenvolvido para colocar em prática conhecimentos de desenvolvimento Front-end, explorando gerenciamento de estados com React, manipulação de eventos, componentes e construção de interfaces responsivas.
